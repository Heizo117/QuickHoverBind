# QuickHoverBind

**QuickHoverBind** es un addon para **World of Warcraft Forever** (WoW 1.6) que permite bindear hechizos de forma ultrarrápida: solo pasa el ratón por encima de un botón de barra de acción y pulsa la tecla que quieras asignarle. Sin menús, sin ventanas de opciones.

## ✨ Características

- **Bindeo instantáneo**: Pasa el ratón por cualquier casilla de barra de acción y pulsa la tecla.
- **Borrado rápido**: Pulsa `ESC`, `Supr` o `Backspace` sobre una casilla para eliminar su bindeo.
- **Compatibilidad total**: Funciona con la barra principal, barras secundarias, barra de mascotas y barra de posturas/formas.
- **Soporte de modificadores**: Puedes bindear combinaciones con `Shift`, `Ctrl` y `Alt`.
- **Icono en el minimapa**: Botón arrastrable alrededor del minimapa para activar/desactivar.
- **Sin conflictos**: Compatible con GlowingBars y otros addons de UI.

## 🚀 Instalación

1. Descarga el addon y descomprime la carpeta `QuickHoverBind`.
2. Colócala en: `World of Warcraft\_forever_\Interface\AddOns\`
3. Reinicia el juego o recarga la UI con `/reload`.

## 🎮 Uso

| Acción | Resultado |
|--------|-----------|
| `/hb` o `/hoverbind` | Activa/Desactiva el modo de bindeo rápido |
| Clic en el icono del minimapa | Activa/Desactiva el modo |
| Ratón encima de casilla + tecla | Asigna esa tecla a la casilla |
| Ratón encima de casilla + `ESC`/`Supr` | Borra el bindeo de esa casilla |
| `ESC` fuera de cualquier casilla | Sale del modo de bindeo |

## ⚙️ Comandos

```
/hb          → Activa o desactiva QuickHoverBind
/hoverbind   → Igual que /hb
```

## 📋 Compatibilidad

- **WoW Forever** (Interface 16001, parche 1.6)
- Barras de acción compatibles: Principal, Secundarias 1-7, Mascotas, Posturas/Formas

## 📝 Notas

- No se puede bindear en combate (limitación de Blizzard).
- Los bindeos se guardan automáticamente en el perfil de tu personaje.
